## A. 车长字段（P0，最严重）

### A1. 车长(mm) 跨批次整组错配
同一车系在不同批次出现差异极大的车长，且**错误值来自其他车型**。

实测实例（比亚迪主口径 BEV）：

| 车系 | 源表车长 | 真实车长 | 偏差 |
|---|---|---|---|
| 唐L | 4600 | **5040** | -440 |
| 海豚 | 5020 | **4290** | +730 |
| 海鸥 | 4680 | **3780** | +900 |
| 元PLUS | 4680 | **4455** | +225 |
| 秦PLUS | 5020 | **4765** | +255 |
| 宋L | 5020 | **4840** | +180 |
| 海狮05 | 4830 | **4520** | +310 |
| 海狮07EV | 4600 | **4830** | -230 |
| 大汉 | 5380 | **5256** | +124 |

量化：比亚迪主口径 BEV 中 **41% 的行**同车系车长极差 >300mm；吉利系仅 6%。

### A2. 车长与轴距成对错配，比值校验失效
车长错时轴距同时错（海豚标 5020/2920，真实 4290/2700），因此：
- `车长/轴距` 比值始终落在 1.40–1.78 的正常区间，**无法用比值识别**
- 「汉」与「海豚」在源表中尺寸完全相同（5020/2920），可确认是成组复制

### A3. 已尝试且无效的修复方案（请勿重复）
1. 同车系众数 → 比亚迪 12 个主力车系众数占比 <60%，无效
2. 同车系最小值 → 对比亚迪有效（错配偏大），对吉利反而引入误差（错配偏小）
3. 按产品型号前缀聚类 → 海豚 BYD7004 组内仍有 5020/4680 两种，无效
4. 用细分市场(segment)校验 → segment 本身也错（海鸥 A00 级标 Car-A）

**建议**：不要试图自动修复。正确做法是建立「车系 → 车长」公开参数核定表
（参考 `15 OEM Portfolio/scripts/_ress_car_len.py`，已含 A/B/C 置信度标注），
未核定的一律剔除，不用公告值、不估算。

### A4. 该缺陷已造成错误结论（重要教训）
用公告错值计算：比亚迪 r(车长,电量) = 0.19 → 曾得出「比亚迪尺寸与电量解耦」的结论。
用核定值计算：r = **0.73**，每 +100mm 增电 **5.4 kWh**。
**结论完全相反。** 任何基于车长的分析都必须先确认车长来源。

## B. 车系命名不统一（P1）

### B1. 多别名拼接
「通用名称」字段把多个别名用逗号/顿号拼在一个单元格：

| 实例 | 实际车型 |
|---|---|
| `元,比亚迪元PRO` | 元 Pro |
| `比亚迪海豚,比亚迪EA1` | 海豚 |
| `TT、TT7、银河TT` | 银河某车型 |
| `EX3,电犀牛,派派` | 几何 EX3 |
| `萌虎,霹雳虎,X` | 吉利某车型 |

量化：比亚迪主口径 BEV 原始车系名 60 种，归一化后仅 36 种；含多别名拼接的写法 10 种。
吉利系原始 47 种 → 归一化 31 种，拼接写法 12 种。

### B2. 同一车型多种写法未合并
| 归一化主名 | 源表中的写法 |
|---|---|
| 宋PLUS | 宋PLUS / 宋PLUSEV / 比亚迪SONGPLUS / SONGPLUS |
| 极氪001 | 极氪001 / 001 / 极氪001FR |
| 极氪009 | 极氪009 / 009 / 009光辉 / 9 |
| 星愿 | 星愿 / 星愿UP / 星愿PRO / 星愿STAR |
| 元 | 元 / 元EV / 元PLUS / 元PLUSEV / 比亚迪元PRO |

### B3. 其他命名问题
- 品牌前缀时有时无：`比亚迪秦PLUS` / `秦Plus` / `秦`
- 大小写不一致：`秦Plus` vs `秦PLUS`
- 含零宽字符：`汉L\u200b\u200b`
- 空格不一致：`银河 L6` vs `银河L6`

**影响**：按车系统计会把一款车拆成多个（虚增车系数），或把不同车混为一个。

**建议**：在底表增加「车系主名」字段（或独立的车型主数据表），
下游只认主名。归一化规则参考 `_ress_oem_bubble_data.py` 的 `norm_series()` 与
`_ress_car_len.py` 的 `ALIAS`。

## C. 产品类型名被当作车系名（P1）

部分行「通用名称」填的是产品类型而非车系名，例如：
`纯电动轿车`、`插电式混合动力多用途乘用车`、`纯电动多用途乘用车`

这些行的车长有 8 种以上（如「纯电动轿车」对应 2917/4610/4640/4660/4694/4760/4863/5010），
**无法归属任何具体车型**，在按车系聚合时成为噪声。

**建议**：底表区分「车系名」与「产品类型」两个字段，缺失车系名的行单独标记。

## D. 品牌/板块归属（P1）

### D1. 企业名含母品牌导致误归
乐道汽车的企业名含「蔚来」，按企业名匹配会把乐道车型归到蔚来。
**规则**：先匹配商标，再匹配企业名。

### D2. 同商标多子品牌
长安深蓝、启源的商标同为「长安牌」，按商标无法区分，需按车系名兜底。

### D3. 排除词误伤自主品牌
「上汽通用」会匹配到「上汽通用五菱」（五菱是自主品牌，不能剔）。
**修正**：排除词用「上汽通用汽车」「上汽大众」，不用「上汽通用」。

### D4. 合资剔除清单需逐家确认
已确认需剔除：上汽通用别克/雪佛兰、上汽大众、长安福特、长安马自达、
广汽本田、广汽丰田、广汽三菱、奇瑞捷豹、奇瑞路虎。
**提醒**：广汽埃安、上汽通用五菱、长安启源是自主品牌，不在剔除范围。

## E. 物理矛盾数据（P1）

| 实例 | 问题 |
|---|---|
| 长安「跨越星光」1.7kWh 标 续航 245–470km | 9 行，物理不可能 |
| 吉利「熊猫mini」4640mm / 788kg | kg/m=170，真实应为 3065mm |
| 极氪009 标 4700mm / 140kWh | 电量密度 29.8 kWh/m，超行业上限（001 为 27.8） |

**建议校验规则**（已用于 `_ress_extract_oem.py` 的 `dq_ok`）：
- `cap < 5kWh 且 续航 > 150km` → 剔除
- `整备质量/车长 ∉ [200, 700] kg/m` → 剔除
- `电量密度 > 28 kWh/m` → 剔除
- 同车系车长极差 > 400mm → 整系标记不可信

## H. 统计口径需对齐（P1）

### H1. 用户给的行数与源表实测不符
| 集团 | 用户给 | 源表实测（有效容量行） |
|---|---|---|
| 蔚来 | 17 | 25 |
| 小米 | 24 | 35 |
| 特斯拉 | 31 | 28 |
| 理想 | 83 | 80 |
| 小鹏 | 100 | 110 |
| 长城 | 250 | 256 |
| 长安系 | 300 | 302 |
| 广汽系 | 362 | 301 |
| 奇瑞系 | 386 | 378 |
| 吉利系 | 464 | 343（主口径） |
| 上汽系 | 548 | 399 |

仅特斯拉基本吻合。差异来源可能是品牌归属范围或去重规则不同，
**需与需求方确认口径后再定稿**，不要反向凑数。

### H2. 已确立的口径铁律
- 统计单元 = **(动力类型, 公告电量值, 电压等级)** 三元组
- 双版本（400V/800V 并存）**先拆分再分列**，不可混算
- **HEV 必须归 ICE**（不可外接充电），误归 PHEV 会虚增新能源占比
- 多标签车系按 `EREV > PHEV > BEV > ICE` 取主分类
- 未披露出口必须 `null`，**禁止填 0 冒充无数据**
- 「系」只取集团自主品牌，合资一律剔除

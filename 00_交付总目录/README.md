# 00_交付总目录 · 唯一对外目录

本目录汇总**数据总表**与**全部分析交付物**，按"给人看"的顺序编排。
构建原件在 `06_自动化与工具/管线工作区/`，本目录下的数据总表为**发布副本**（与原件同 sha256，见 `03_核查与台账/发布清单.json`）。

## 01_数据总表
| 文件 | 说明 |
|---|---|
| `NEV公告参数汇总表（341~412批）.xlsx` | 权威数据底表：5,475 行 × 45 列，覆盖工信部第 341~412 批新能源乘用车公告；含销量三列（汽车之家 2026-09 口径）、车系ID、销量覆盖状态、续航工况标注 |
- 主表 sheet `NEV公告参数汇总`：一行 = 一条公告记录（**不是一款车**；同车系多行共享同一个月销量）
- 台账 sheet：`变更记录`（逐格留痕）、`缺失值补缺台账`、`错误纠正台账`、`官方目录核实台账`、`官方复核差异台账`、`412批合并台账`、`多批次合并台账`
- 口径全文：`05_文档与流程/` 下的《销量口径规范》《核心论断与建议纲要》

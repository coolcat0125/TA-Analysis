# 候选分析看板（三选一）

基于 `NEV公告车型行业分析_数据底表.xlsx`（v4.3.6，4,613 款）生成的三款候选看板。三款**共用同一套数据抽取与图表内核**，仅信息架构与视觉风格不同，选定后可直接以该款为基础迭代。

| 方案 | 文件 | 定位 | 风格 |
|---|---|---|---|
| A 行业简报式 | `A_editorial/` → `dist/看板A_行业简报式.html` | 对外汇报 / 报告配图 | 米白纸感、衬线标题、长页面章节导读 + 结论导语 |
| B 分析控制台 | `B_console/` → `dist/看板B_分析控制台.html` | 内部分析师日常使用 | 深色侧边栏 + 分页签，密度最高，含明细表 |
| C 移动卡片式 | `C_mobile/` → `dist/看板C_移动卡片式.html` | 售后 / 一线手机查看 | 底部导航 + 横滑卡片 + 胶囊筛选，桌面自动展开三列 |

## 共同功能
- **响应式**：电脑端多列布局，手机端单列 / 横滑，均已适配 ≤640px 竖屏。
- **全局筛选（切分字段）**：动力类型（全部 / BEV / PHEV-EREV）、年份区间、细分市场多选（含「主流五档」快捷）、细分指标（车型数 / 续航 / 容量 / 功率 / 整备质量）、指标探索器（8 个年度指标任选）。
- **31 张图 / 7 个模块**，沿用底表目录的分析维度：总览 → 续航与电池 → 驱动与能效 → 供应商格局 → 细分市场 → 相关性与同比 → 年度综合指标。
- **口径原则**：与仓库现行看板一致——均值口径；缺失不计入分母（分布图按占比）；BEV / PHEV 分列并可开关；供应商分析注明有值子集；410 批占位计入 2026。
- 自包含 HTML（ECharts 内嵌），双击离线可用。

## 使用
```bash
python3 candidates/build.py      # 重新抽取底表 → 打包 dist/ 三个自包含 HTML
python3 candidates/serve.py      # 本地预览 http://localhost:8080/
```
`extract_base_data.py` 负责底表 → JSON；`core.js` 为图表内核（option 构造器 + 状态）；`filters.js` 为筛选条；各方案目录只含各自的页面骨架与主题色。

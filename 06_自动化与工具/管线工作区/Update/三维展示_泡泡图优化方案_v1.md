## 0. 背景与现状（方案依据）

当前看板「自定义分布」面板的能力（来自 `generate_dashboard.py` 实证）：

- **维度自由选择**：X 轴、Y 轴各有一个下拉框（`cdX` / `cdY`），从「可量化字段」中任选；提供「交换 X/Y」「复位」。
- **Z 轴 → 泡泡直径**：Z 轴下拉框（`cdZ`，"（不使用 · 散点图）"为默认）。选定 Z 后散点自动变为泡泡图，泡泡直径 ∝ √Z（面积≈正比数值），并有「泡泡比例」滑杆（`cdZScale`，默认 100%）与「自动调节」（随视窗缩放）开关。
- **辅助层**：「等级区段」（按轴距阈值画 Car/SUV/MPV 分级 markLine）、视窗缩放复位、双击复位。
- **已存在的三维模式**（v4.9.4 / v4.9.6）：按钮 `cd3d`（"三维展示"）在已选定 Z 时，把 **Z 从泡泡直径改为垂直柱高**，用 `bar3D` + `grid3D` 渲染；两条 `visualMap`（continuous）按 Z 高度对 BEV / PHEV-EREV 两系列做**同色系 浅→深**梯度着色，右侧带梯度刻度；视角按钮「视角复位 / 俯视 X-Y」，支持左键旋转、滚轮缩放、右键平移；WebGL 失败时回退二维泡泡图。
- **可量化字段池**：轴距(mm)、车长(mm)、整备质量(kg)、纯电续航里程(km)、电池容量(kWh)、电池能量密度(Wh/kg)、百公里电耗(kWh/100km)、前电机功率(kW)、电机总功率(kW)、系统扭矩(Nm)、综合油耗(L/100km)、发动机排量(mL)、发动机功率(kW)、批次。
- **技术栈**：ECharts 5 + echarts-gl 2.x，均已本地内置（离线可用，无需 CDN）。

> **关键结论**：仓库**已落地「海拔柱状图 + 同色系梯度」的雏形**（即下方方案一的现状版）。本方案的价值在于给出**三条可并行的深化路线**，并补齐「维度可调 + 梯度可调」的显式控制，供决策者取舍。

## 1. 设计总原则（三方案共同遵循）

1. **三维度对应关系优先**：三个参数分别落到三个"视觉通道"，避免只用一种编码承载多维度。
2. **维度可调**：X / Y / Z 三个下拉框均可换字段，切换后即时重算坐标范围、色阶与统计口径。
3. **梯度可控**：色带（ramp）预设可选（同色系浅→深 / 冷暖双色 / 分级色阶），并提供"梯度强度 / 分段数 / 是否连续"开关。
4. **不破坏现有能力**：2D 泡泡图、等级区段、缩放复位、导入导出等一律保留；三维仅作**并列视图**，可随时切回二维。
5. **离线自包含**：不新增外部依赖，仅用已内置的 `echarts-gl`（`bar3D` / `scatter3D` / `surface3D` / `lines3D`）。
6. **降级安全**：WebGL 不可用时自动回退二维泡泡图并提示（沿用现有 `renderCustom3D` 的返回 false 回退机制）。

---

## 2. 方案一：海拔柱状图（3D 立柱 + 同色系海拔梯度）

> 即仓库现有 v4.9.6 方向的**产品化深化版**；改动最小、风险最低。

**视觉隐喻**：把 X-Y 平面当作"地面经纬"，每款车型是一根立柱，**柱高 = Z**（自底面 0 起算 → 海拔感），**柱色 = Z 的连续梯度**（同色系浅→深），形成"地形海拔图"。

| 维度通道 | 映射 | 可调控件 |
|---|---|---|
| X 轴 | 维度 1（如 轴距 mm） | `cdX` 下拉 |
| Y 轴 | 维度 2（如 纯电续航 km） | `cdY` 下拉 |
| 柱高 Z | 维度 3（如 电池容量 kWh） | `cdZ` 下拉（必选）+「柱高倍率」 |
| 颜色 | Z 值梯度（浅→深） | 色带预设 + 右侧梯度刻度 |

**深化点（相对现状）**
- 新增**色带预设选择**：同色系浅→深（现状）/ 单色系三档 / 冷暖双色；`visualMap.inRange.color` 可配置。
- 新增**柱高倍率滑杆**（替代/并列现有 `zScale`），控制立体夸张度。
- **底面网格辅助**：X/Y 主刻线投影到底面，缓解 3D 遮挡下的读数困难。
- **两系列分列着色**：BEV（暖橙系）与 PHEV/EREV（冷蓝系），保持现有 `CD_RAMP` 双色带，各配一条梯度刻度。

**技术要点**：`series.type='bar3D'`，`barSize:[1.5,1.5]`，`grid3D` + `xAxis3D/yAxis3D/zAxis3D`，`visualMap.continuous`（`dimension:2`，`seriesIndex` 分别绑定）。交互：`grid3D.viewControl` 旋转/缩放/平移，`视角复位`（等轴测）/`俯视 X-Y` 预设。

**优点**：柱体体积感强、单值读高直观、与现有代码复用度最高（仅增强控件）。
**缺点**：数据量大（数千款车型）时立柱密集易相互遮挡；柱高起算需固定 0 才不失真。
**适用**：强调"第三个参数的绝对高低排序"时。

## 3. 方案二：三维梯度泡泡图（scatter3D 球体 + 连续色彩梯度）

> 把"泡泡"从平面升级到三维空间，**位置承担三维度**，**颜色梯度承担第四通道（可选）**。

**视觉隐喻**：每款车型是一颗悬浮在三维箱体内的**球体**，三个坐标轴直接对应三个参数；球体**颜色由 Z（或另选字段）的连续梯度**决定，**直径由第五字段**（可选，如样本/功率）决定。

| 维度通道 | 映射 | 可调控件 |
|---|---|---|
| X / Y / Z 位置 | 维度 1 / 2 / 3 | `cdX` / `cdY` / `cdZ` 三个下拉 |
| 球体颜色 | 维度 3 或另选第 4 字段 | `cdColor` 下拉 + 色带预设 |
| 球体直径 | 可选第 5 字段 | `cdSize` 下拉（默认关闭=等大） |

**深化点**
- **四通道编码**：位置(3) + 颜色(1) + 大小(1)，最契合"三/四维参数关系"的整体呈现。
- **颜色与高度解耦**：当 Z 已是位置轴时，颜色可改绑**另一字段**（如 能量密度），避免"同值重复编码"，信息量更高。
- **梯度刻度**：右侧 `visualMap` 连续色带 + 数值标注；支持色带预设与分段数。
- **点云性能**：启用 `large:true` / `largeThreshold`，或按动力类型分系列半透明（`rgba(...,.45)`）以缓解重叠。

**技术要点**：`series.type='scatter3D'`，`symbolSize` 可用 `value[3]` 映射；`visualMap.continuous`（`dimension` 指向颜色字段）；颜色字段与位置字段独立配置。

**优点**：信息密度最高（4–5 维同屏）、三维关系最"散点真实"、旋转后结构层次感强。
**缺点**：密集点云遮挡明显、精确读数弱于柱状；颜色与位置若绑同字段会冗余（需提供解绑）。
**适用**：探索"多参数联合分布形态 / 聚类与离群"时。

## 4. 方案三：梯度地形曲面图（surface3D / 高度场云图）

> 将 X-Y 平面**网格化聚合**，Z 取每格均值或样本数，生成连绵"地形曲面"，颜色梯度=高度。牺牲个体、换取**整体格局**。

**视觉隐喻**：两个参数铺成地面网格，第三个参数聚合成**起伏山峦**；峰=高值密集区，谷=低值/空区，颜色深浅=海拔。

| 维度通道 | 映射 | 可调控件 |
|---|---|---|
| 网格 X | 维度 1（按档位/等分） | `cdX` + 网格粒度 |
| 网格 Y | 维度 2 | `cdY` + 网格粒度 |
| 曲面高度 Z | 维度 3 的**聚合值**（均值/中位/计数） | `cdZ` + 聚合方式下拉 |
| 颜色 | 高度梯度（浅→深/冷暖） | 色带预设 |

**深化点**
- **聚合可切换**：均值 / 中位数 / 样本计数（空网格可显示为"低洼/缺口"，直观暴露数据覆盖盲区）。
- **梯度可控**：`visualMap` 支持分段（piecewise）或连续，色带预设同上。
- **等高线辅助**：叠加投影等高线（`lines3D` 或底面映射），辅助读数。
- **按动力类型双曲面**：BEV / PHEV 可分别出图或叠加半透明对比。

**技术要点**：`series.type='surface3D'`（需 `data` 为 `[x,y,z]` 规则网格）；聚合在渲染前用一次网格分箱计算；`grid3D` + `visualMap` 同前。

**优点**：整体规律/趋势最直观、抗个体噪声、天然暴露覆盖缺口；视觉冲击强，适合汇报演示。
**缺点**：丢失个体明细（不可下钻到单车）、聚合口径需明示（均值 vs 计数结论不同）。
**适用**：向决策者汇报"两参数交互下的第三参数整体高低格局"时。

## 5. 三方案横向对比

| 维度 | 方案一排海拔柱 | 方案二三维梯度泡泡 | 方案三梯度曲面 |
|---|---|---|---|
| 三维度映射 | X/Y + 柱高Z + 色Z | X/Y/Z 位置 + 色(+大小) | X/Y 网格 + 曲面高Z + 色 |
| 信息密度 | 中 | **高**（4–5 通道） | 中（聚合后） |
| 个体可读性 | **强**（单值读高） | 中（点云遮挡） | 弱（聚合，不可下钻） |
| 整体格局感 | 中 | 中 | **强** |
| 遮挡风险 | 高（柱密） | 高（点密） | 低 |
| 与现有代码复用 | **最高**（现状深化） | 中（新增控件与渲染） | 中高（新增聚合层） |
| 实现风险 | **低** | 中 | 中 |
| 典型场景 | 第三参数排序/达标核对 | 多参数联合分布探索 | 汇报演示/覆盖盲区 |

## 6. 统一交互与"维度/梯度可调"落地（三方案共用）

1. **控制条扩展**：在现有 `cdX / cdY / cdZ / 泡泡比例 / 交换 / 复位` 旁，新增
   - 「色带预设」下拉（同色系浅→深 / 三档单色 / 冷暖双色）
   - 「梯度类型」切换（连续 / 分段，分段数可调）
   - 「球径字段 / 柱高倍率」（随方案显示）
2. **2D ⇄ 3D 并列**：保留现有 `cd3d` 切换按钮语义，二维泡泡图与三维视图随时互切（沿用"clear 后全量重建 + WebGL 失败回退"机制）。
3. **视角系统**：沿用 `视角复位`（等轴测）/`俯视 X-Y`（正对平面=等同原二维布局），可再加"侧视 X-Z / Y-Z"预设。
4. **状态一致性**：切字段→重算坐标范围与色阶并同步梯度刻度；缩放→更新视窗文案；复位→还原默认字段与视角。
5. **降级与性能**：WebGL 不可用回退二维并 toast；大数据启用 `large`、半透明与节流重绘（沿用 `scheduleCdRender` 的 rAF 节流）。

## 7. 建议与下一步

- **推荐次序**：**方案一（产品化现有柱状海拔）→ 方案二（三维梯度泡泡）→ 方案三（梯度曲面）**。
  理由：方案一复用度最高、风险最低，可先把现有雏形补齐"色带/倍率"控件即交付；方案二信息密度最高，最能回应"三个维度参数对应关系 + 梯度效果 + 维度可调"的核心诉求；方案三作为汇报场景补充。
- **建议组合**：以方案二为主视图、方案一为"读高"辅助视图，方案三作为"汇总/汇报"模式，三者共用同一控制条。
- **落地约束**：均**不改主程序业务流程**，仅在「自定义分布」面板内扩展渲染分支与控件；由 `generate_dashboard.py` 统一生成，保持发布版与工作版策略一致（发布版可按需剥离 3D，沿用 v4.9.6 现有开关）。

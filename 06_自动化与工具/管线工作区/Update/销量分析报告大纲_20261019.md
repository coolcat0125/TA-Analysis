## 1. 报告定位与写作纪律

**定位**：面向公司领导层的中长期研判材料。不是公告数据的复述，而是"公告供给侧 × 市场销量侧"的
联动解读，落点在**结构 / 集中度 / 迁移 / 转化**四类有数据支撑的观察。
**一体两面**（纲要 §0）：摘要= 5 条结论 + 3 条建议；详细展开= 正文；总结= 回扣 5 条结论。

### 1.1 六条写作纪律
1. **高屋建瓴**：每章开头的"结论框"先给判断，再给数据，最后给建议；不写流水账。
2. **数字零手写**：所有业务数字经 `NUM_SRC` 注册表从 A-JSON 读取（`render()` + `guard_no_literals()` G1 门禁）。
3. **口径显式**：数据源、快照月、口径决策、车系级去重、覆盖率三口径 + 四分桶，全部写入第一章与附录 A。
4. **不确定性显式**：推断处标"推论"并给依据强度；样本不足处直接标「样本不足，不解读」。
5. **建设性**：第七章每条建议对应"数据依据 + 建议动作 + 观察指标"。
6. **可追溯**：每章标注所支撑的纲要结论编号（见 §3 各章头部）。

### 1.2 写作禁区（纲要 §4，逐条落地为脚本门禁）
| 禁区 | 落地手段 |
|---|---|
| ❌「销量高 ⇒ 技术好/产品强」无支撑因果 | 文本自检词表（`销量高.*技术`、`领先.*说明`）+ 人工终审 |
| ❌ 不可量化修辞（遥遥领先/断层第一/全面碾压） | 文本自检词表硬门禁，命中即 fail |
| ❌ 把**公告车型数**当**在售车型数** | 全文只用 `coverage.row.covered` 表"在售"，`conversion.*` 的公告数一律带"公告"限定词 |
| ❌ 用底表**行级**加总当市场规模 | 市场规模只用 `structure.sales_total_dedup`；`rowlevel_naive` 仅作反例对照 |
| ❌ 推测未公开战略意图 / "据悉""业内人士认为" | 文本自检词表 |
| ❌ 图表标题缺口径与月份 | 表标题格式模板：`<表名>（2026-09 车系级月销 · 新能源榜）` |

### 2.5 叙事注入机制（`fill_report_narrative_v4932.py` 既有做法，硬约束落地）
- **标签寻址**：`label_map()` 建 `(节名[:16], 列头[:12], 行标签[:12]) → 浮点值` 三元组映射（各段先 `re.sub(r'\s+','')`）。新章数字注入一律走这三元组，**禁止文档级全局数值映射**（AGENTS 2026-09-29：曾把 v4.9.23 改成 v4.9.389）。
- **质量门控**：段落数字可映射率 ≥90% 才整段注入；否则按 `(?<=。)|(?<=；)` **句子级修剪**，修剪后 ≥40 字才收；`1900≤v≤2100` 保护年份；跳过含 `底表 v4` 或 `第\d+[-~]\d+批` 的句子；已含叙述的节直接跳过。
- **vMerge 绕过**：表格写入必须 `tr = t._tbl.tr_lst[ri]; tc = tr.tc_lst[ci]; _Cell(tc, t).text = txt`，禁止 `Table.cell()`（`_cells` 索引错位抛 IndexError）。
- **备份**：自动备份名**必须含版本号 + 时间戳** + 存在性检查，否则多次运行覆盖原始备份（AGENTS 2026-09-27）。

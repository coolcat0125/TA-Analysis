# 历史版本归档索引

> 本目录保存 **v3.3.0 ~ v4.4.2** 的历史快照，按「版本_日期」命名，时间顺序排列。
> 仓库根目录只保留**当前最新版**（写作时 v4.4.7）的交付物、管线脚本与文档，遵循「一版一源」。
> 版本变更的完整文字记录见根目录 [`CHANGELOG.md`](../CHANGELOG.md)（42 个版本，v1.0.0 起全量保留）。

## 一、归档规则

| 项 | 约定 |
|---|---|
| 目录命名 | `<版本号>_<YYYYMMDD>`，按时间升序排列 |
| 归档内容 | 该版本当时的底表 / 看板 / 生成脚本 / 审计件的快照 |
| 主题备档 | `*_pre-*_backup.xlsx` 为变更前底表备份，用于回滚与逐格追溯 |
| 不入库 | 敏感件（登录授权截图）、空文件、正本已含的文档片段 |

## 四、检索指引

- **要最新数据**：用根目录底表与两版看板，勿用本目录快照
- **要复现某版结论**：进入对应版本目录，取该版底表 + 该版生成器
- **要回滚**：取 `*_pre-*_backup.xlsx`，并核对 `CHANGELOG.md` 中该版的变更范围与底纹标注
- **要查某格来源**：底表内【变更记录】/【参数对齐记录】工作表 + 对应版本 CHANGELOG 条目

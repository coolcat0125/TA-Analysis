### ⚠️ 为什么脚本与数据同目录

51 个脚本用 `Path(__file__).parent` 定位数据，43 个硬引用主汇总表，`audit-output` 被 33 个脚本引用。拆开则管线失效。故整体作为自包含单元，**脚本零修改可运行**。

**运行方式**：
```bash
cd "06_自动化与工具/管线工作区"
python audit_data.py --gates quality_gates.json
python generate_dashboard.py
```

## 07 公告与减免购置税

工信部装备工业发展中心「公告发布」栏目正式发布件的本地归档，供溯源与核对使用。

| 位置 | 内容 |
|---|---|
| `07_公告与减免购置税/README_归档说明.md` | 命名规则、历史命名变化、覆盖情况、缺口说明、工具用法 |
| `00_索引/批次总览.csv` | 全量 239 批官方目录（第173至411批，逐批标注持有情况） |
| `00_索引/文件清单.csv` | 390 个文件的批次/日期/大小/路径 |
| `00_索引/完整性核查.md` | 年份覆盖表、缺口清单、格式校验结果 |
| `01_公告/<年份>/` | 道路机动车辆生产企业及产品（第X批），239 份，2008-2026 |
| `02_减免购置税/<年份>/` | 免征／减免车辆购置税的新能源汽车车型目录，74 份，2020-2026 |
| `03_车船税/<年份>/` | 享受车船税减免优惠的节能与新能源汽车车型目录，74 份，2020-2026 |

命名规则：`第{公告批次}批_{发布日期YYYYMMDD}_{官方附件名}.{扩展名}`

抓取脚本：`06_自动化与工具/_scripts/announce_archive/`（`fetch_batch_catalog.py` 清单 / `download_batches.py` 下载 / `build_index.py` 索引 / `check_completeness.py` 核查），走企业代理。

> 口径提示：归档按发布日期归年（2026 年 = 第403至411批）；底表按批次段把 401 至 412 批记作 2026 年，两者不同。第 412 批目前仅公示，未正式公告。2014 至 2019 年独立发布的免征购置税目录不在该栏目，列为待补充。

## Coordination rules
1. Only one Agent at a time may modify a canonical master dataset.
2. Independent discovery Agents may work in separate candidate files.
3. Verification Agents consume candidate files and produce verification ledgers.
4. Integration happens only after QA.
5. Every task must record its input and output SHA.
6. A stale task must re-read this file before resuming.
7. If HEAD changed since task start, the Agent must revalidate its assumptions.
8. The Orchestrator performs final acceptance.

# TA-Analysis v4.9 Roadmap

## Mission

Turn TA-Analysis into a continuously maintainable NEV technology-intelligence foundation covering vehicle, battery, electric drive, suppliers, evidence, product portfolios and technology evolution.

## Workstreams

### P0 — Governance and baseline
- shared Agent contract
- state machine
- data contract
- evidence semantics
- handoff protocol
- baseline freeze

### P1 — Battery intelligence
- battery/cell supplier candidate discovery
- independent verification
- battery parameter extraction
- 80 kWh priority set
- battery evidence ledger

### P1 — Electric-drive intelligence
- motor/e-drive supplier candidate discovery
- motor parameter extraction
- OCR pipeline
- power/torque/rpm consistency checks
- e-drive evidence ledger

### P1 — Evidence and QA
- source precedence
- conflict resolution
- cross-brand contamination detection
- before/after audit
- regression gates

### P2 — Product portfolio
- supplier master
- battery product families
- motor/e-drive product families
- application vehicle mapping
- generation/technology evolution

### P2 — Technology trend
- historical trajectory
- current state
- forward scenarios
- explicit fact/estimate/scenario separation

### P3 — Dashboard and deliverables
- supplier landscape
- battery technology map
- electric-drive landscape
- technology evolution
- report/PPT/Excel integration

## Delivery rule

Every workstream produces auditable artifacts in Git and updates the persistent Agent state. No downstream Agent should need private conversation context to resume the work.

## Success condition

A new Agent, starting from the repository alone, can determine:
1. what has been completed;
2. what is currently running;
3. what data is authoritative;
4. what evidence supports it;
5. what remains blocked;
6. what exact task should be executed next.

# TA-Analysis · 新能源汽车公告数据分析

针对工信部《道路机动车辆生产企业及产品公告》新能源汽车参数库（第 341~410 批）的分析工具集：一键生成交互式数据看板，配套行业分析报告、演示文稿与数据底表。

## 仓库结构

| 文件 | 说明 |
|---|---|
| `generate_dashboard.py` | 看板生成器（核心）。读取公告参数汇总 Excel，产出自包含 HTML 交互看板 |
| `NEV公告参数汇总表_合并版（341~410批）.xlsx` | 源数据（341~410 批合并，4414 条，含 `NEV公告参数汇总`、`批次时间表`、`变更记录` 等工作表；末页【版权声明】） |
| `NEV公告数据看板.html` | 生成的看板（完整版，含数据质量检查，双击离线打开） |
| `NEV公告数据看板_发布版.html` | 生成的看板（发布版：保留全部功能，隐藏【数据质量检查】区块，页头 RELEASE 徽标） |
| `add_batch_time_v4.py` / `fill_consensus_v4.py` | 底表工具：批次时间表补充 / 同车型共识补全（可复跑） |
| `echarts.min.js` / `xlsx.full.min.js` | 生成器运行依赖（构建时内嵌进 HTML，需与脚本同目录） |
| `NEV公告车型行业分析报告.docx` | 行业分析报告（咨询版，文末版权段） |
| `NEV公告车型行业分析_演示文稿.pptx` | 管理层演示文稿（首页右下角版权标注） |
| `NEV公告车型行业分析_数据底表.xlsx` | 分析数据底表（封面/说明页版权行，24 张分析页 A1 批注附注版权） |
| `CHANGELOG.md` | 版本记录 |

> 旧版底表（341~408 批 / 341~409 批）、v3.1/v3.3 数据补充审计表与 v3.6 调试产物已归档至 `archive/`，详见 [archive/README.md](archive/README.md)。

## 快速开始

```bash
# 依赖
pip install openpyxl

# 生成看板（默认读取同目录汇总表 341~410批，输出 NEV公告数据看板.html）
python3 generate_dashboard.py

# 或指定输入输出
python3 generate_dashboard.py <公告参数汇总.xlsx> <输出看板.html>

# 发布版（保留全部功能，隐藏【数据质量检查】区块，输出 NEV公告数据看板_发布版.html）
python3 generate_dashboard.py --release
```

生成后双击 HTML 即可在浏览器离线使用（ECharts 与 SheetJS 已内嵌，无需联网）。

## 看板功能（v3）

- **筛选**：批次范围、动力类型（BEV / PHEV-EREV）、细分市场多选下拉
- **六大页面**：总览 / 电机系统 / 发动机系统 / 电池系统 / 企业与品牌 / 数据管理
- **统计口径**：缺失或未填报值不计入统计与百分比分母；物理范围外异常值自动置空
- **趋势线**：散点图含最小二乘趋势线（按 BEV / PHEV-EREV 分列，图例可开关）；折线图缺失批次以趋势线衔接（同色淡色虚线）
- **企业与品牌**：Top 8 企业公告量批次演进、企业×细分市场矩阵、各批次新进入企业跟踪、品牌 Top 15、免购置税车型占比趋势
- **数据管理**：当前筛选结果导出 Excel/CSV（22 字段可勾选，含产品型号/商标/免购置税）；导入最新公告汇总表后页面内实时刷新全局图表；车型明细查询表支持企业/商标/型号搜索、列排序与翻页浏览
- **其他**：白天/黑夜模式切换、数据质量页置底

## 数据处理口径（重要）

1. **细分市场**：`/` 等占位值视为未填报，不显示、不计入统计
2. **电池类型归一化**：`磷酸铁锂电池`/`磷酸铁锂蓄电池`/`LFP` 等杂称合并为 `磷酸铁锂`；`三元锂`/`镍钴锰`/`NCM` 合并为 `三元锂`；构成趋势按已填报数据百分比占比核算
3. **物理范围校验**：整备质量、续航、容量、能量密度、电耗、功率、扭矩、油耗、排量等按 BEV / PHEV-EREV 分别设定合理区间，越界值视为录入异常并置空
4. **PHEV/EREV**：数据层保留 `PHEV` 原始编码，展示层统一为 `PHEV/EREV`

## 协作约定

- **版本号**：语义化版本（主版本.功能版本.修订版本），重大口径变更升主版本；发布时打 tag（如 `v3.0.0`），详见 `CHANGELOG.md`
- **数据更新流程**：新版公告汇总表替换 `NEV公告参数汇总表_合并版（341~410批）.xlsx`（或新命名并在 README 登记）→ 重跑 `generate_dashboard.py` → 提交数据与看板产物 → 在 `CHANGELOG.md` 登记批次范围变化
- **命名约定**：数据文件 `NEV公告参数汇总表_合并版（起~止批）.xlsx`；看板固定输出 `NEV公告数据看板.html`
- **提交规范**：`feat:` 新功能 / `fix:` 修复 / `data:` 数据批次更新 / `docs:` 文档。例：`data: 更新至410批并重生成看板`
- **口径变更**：任何统计口径调整（如归一化规则、物理范围）须同步修改 `generate_dashboard.py` 内 `norm_bt` / `NUM_RANGES` / `clean_seg` 及其 JS 侧对应函数（页内导入路径），并在 CHANGELOG 说明

## 已知边界

- 页内导入要求表结构与源汇总表一致（首列批次、第 10 列动力类型等固定列位）
- 扭矩字段解析自"功率/扭矩"复合格式，纯数值单元格不计入


## 数据质量与版本审计

运行 `audit_data.py` 可对当前公告源表生成 SHA-256 可追溯的 JSON/Markdown 审计报告，检查字段覆盖率、物理范围、批次分布和质量门禁：

```bash
python3 audit_data.py --gates quality_gates.json --strict
```

详见 [AUDIT.md](AUDIT.md)。新增公告批次后，应一并提交源表、看板产物与 `audit-output/` 下的审计报告。

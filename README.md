# TA-Analysis · 新能源汽车公告数据分析

工信部《道路机动车辆生产企业及产品公告》新能源乘用车参数库的构建与分析仓库。底表覆盖第 341 至 412 批，第 412 批为公示状态。分析口径、看板、报告与演示文稿全部同源。

## 目录导航

| 目录 | 内容 | 什么时候来这里 |
|---|---|---|
| `00_索引/` | 目录导航、归档迁移记录、文件分类清单 | 不确定某个文件放在哪 |
| `01_当前数据/` | 核定底表 v1、能耗原始数据 | 要取数、核对原始口径 |
| `00_交付总目录/` | **数据总表 + 全部交付物**（报告/演示稿/54 表/看板/移动版），唯一的对外交付位置 | 要拿结论、要对外汇报、要取权威数据表 |
| `03_核查信息/` | 核查索引、异常值清单、电池类型跨源差异清单 | 要验证某个数字是否可靠 |
| `04_历史数据/` | 合并前备份、旧抓取日志 | 要追溯某个版本的来历 |
| `05_文档与流程/` | 仓库文档、口径说明、数据字典、更新日志、工作分派 | 要查口径定义、改版记录 |
| `06_自动化与工具/` | 管线工作区（脚本与数据同目录）、DCD 补全流水线、工具链 | 要复跑看板、重生成交付物 |

`06_自动化与工具/管线工作区/` 是一个自包含运行单元：51 个脚本用 `Path(__file__).parent` 定位数据，43 个脚本硬引用主汇总表。整体移动不破坏运行，拆开则管线失效。

## 四条常用查询路径

**取数**：`01_当前数据/核定底表/data/NEV公告核定底表（341~412批）_v1.xlsx` 的「明细全量」工作表。字段含义见 `01_当前数据/核定底表/docs/数据字典_v1.md`。

**取结论**：`00_交付总目录/` —— `01_数据总表/` 是数据底表发布副本（与构建原件同 sha256），`02_分析交付物/` 是四件套。报告看 `.docx`，汇报用 `.pptx`（原生可编辑图表），交互查询用 `NEV公告数据看板.html`（双击离线可用，ECharts 与 SheetJS 已内嵌）。

**查口径**：`05_文档与流程/docs/` 与 `01_当前数据/核定底表/docs/`。前者是仓库级说明，后者是底表级口径说明与数据字典。

**查证据**：`03_核查信息/` 是索引，实物在 `06_自动化与工具/管线工作区/audit-output/`（审计报告、证据、门禁产物）。

## 复跑

```bash
cd "06_自动化与工具/管线工作区"
python audit_data.py --gates quality_gates.json   # 数据门禁
python generate_dashboard.py                      # 重生成看板
```

依赖仅 openpyxl。看板为自包含 HTML，生成后双击即可离线打开。

## 版本与溯源

- 版本记录见 `05_文档与流程/仓库文档/CHANGELOG.md`，状态锚点见 `PROJECT_STATUS.md`。
- 任何文件的版本不得凭版本号判断，一律以 git 提交记录为准。历史上出现过同一版本号两侧内容不同的情况。
- 工信部公告与购置税目录的原始归档（239 批，2008 至 2026 年，约 851 MB）不在本仓库内，仅保留批次索引 `00_索引/文件清单.csv` 供溯源。原始件因体积过大保持本地留存，需要时按索引中的批次号与发布日期调取。

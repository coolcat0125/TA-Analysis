## 二、真实浏览器验证（本机 Edge 156.0.4314.58）

- headless：`msedge --headless --dump-dom <url>` → 输出 0 B（同站 `https://example.com` 可正常 dump 8 KB，证明机制可用）。
- 去掉 headless、`--window-position=-32000,-32000` 离屏有头 → 输出同样 0 B。
- 证明**不是无头检测**，而是站点对未登录会话直接返回空体。

## 三、登录态检查

- Edge 默认配置 cookie 库：`…\User Data\Default\Network\Cookies`（94,208 B，总 64 条 cookie）中 `host_key like '%dongchedi%' or '%dcdapp%'` **命中 0 条**。
- 结论：本机无懂车帝登录态可用。
